## 🚀 核心四大特色 (Key Features)

### 1. 雙色螢光筆精準重現 (Dual Highlighting System)
- 🌕 **黃色螢光筆【基礎防禦：形式標記】**：標示題幹之「最恰當/何者非/下列敘述何者正確」等核心限定詞與文章結構骨幹，鍛鍊審題專注力，嚴防粗心。
- 🟢 **綠色螢光筆【進階攻擊：內涵推論】**：深入解構文章之關鍵因果句、情感轉折、深層隱喻，並標出選項陷阱與謬誤之處，一擊命中考點！

### 2. 文言文全篇白話譯文對照 (Classical Chinese Translation)
- 針對古詩（如《迢迢牽牛星》、《慈烏夜啼》）及五大閱讀題組文言文本，均提供精準流暢之全篇白話文對譯，徹底破除古文閱讀障礙。

### 3. 成語、字形音義全面深究 (Comprehensive Annotation)
- 每道國字注音題均附單字本義與整句詞語情境說明。
- 四選一成語題之四大選項（A、B、C、D）逐一提供完整釋義與語境用法辨析。

### 4. 線上作答與即時交卷計分 (Interactive Testing)
- 支援「純淨作答模式」與「顯示詳解模式」自由切換。
- 學生可於線上逐題勾選作答，點擊「交卷計分」即時檢視客觀得分與答錯題目分析。
